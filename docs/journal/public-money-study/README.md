# The Public-Money Study — public learnings journal

DoxaBase's second external case-study domain: UK public spending
records. We are — theoretically — building a tool for data
journalists: given one public body's published expenditure, how much
of it can be connected to identifiable organisations and published
procurement records, with what confidence, on what evidence? The
work is strictly apolitical: we study the data's structure, its
failure modes, and the epistemics of entity resolution, never the
politics of any payment. The domain was chosen because it is a
genuinely challenging dataset with a major network aspect —
payments, suppliers, corporate identity, and procurement records
form a graph that resists naive joining in instructive ways.

The working sessions, source data, and body-specific detail live in
a private repository; these articles publish what the work TEACHES —
the recurring traps, the methods that survive contact with real
files, and what the DoxaBase discipline looks like on a second
domain. Same rules as everything else here: claims carry evidence,
negative results are findings, and the vocabulary gets distilled
from cases rather than designed in advance.
